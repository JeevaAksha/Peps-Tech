# Personal Portfolio Website

## Overview

This is a responsive Personal Portfolio Website developed using HTML and CSS. The website showcases my profile, skills, projects, education, certifications, and contact information in a professional and visually appealing manner.

The portfolio serves as a digital resume and can be used for internships, placements, freelancing opportunities, and professional networking.
